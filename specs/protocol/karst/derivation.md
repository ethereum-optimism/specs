## Activation Block Rules

The first block with a timestamp at or after the Karst activation time is considered the _Karst activation block_.

On the Karst activation block, in addition to the L1 attributes deposit and potentially any user deposits from L1, a
set of deposit transaction-based upgrade transactions are deterministically generated by the derivation pipeline.

The network upgrade transactions are described in [Deposits](./deposits.md).
